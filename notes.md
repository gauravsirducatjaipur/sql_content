### Create database command
- create database database_name;


### Enter/Select database command
- use database_name;

### To show all database - command
- show databases;

### To show all table in particular database - command
- show tables;

### create table - command

    column_name1 &nbsp;&nbsp;&nbsp;   datatype,\
    column_name2 &nbsp;&nbsp;&nbsp;   datatype,\
    column_name3 &nbsp;&nbsp;&nbsp;   datatype,\
    column_name4 &nbsp;&nbsp;&nbsp;   datatype,



    column_name_n &nbsp;&nbsp;&nbsp;   datatype,\

### to show all columns of table - command
- select * from table_name;

### to show particular columns of table - command
- select column_name1, column_name2, column_name_n from table_name;
